# Retro Console Checker

**Know your console.** A free retro-hardware identification and ownership reference by RetroReplay UK.

## App features
- Model-number and name search with punctuation-insensitive matching
- Manufacturer, family and model browsing
- Detailed hardware, media, connection and identification information
- Local **My Collection** storage (no account required)
- Side-by-side model comparison
- Shareable model links
- Offline-capable Progressive Web App
- Installable on supported desktop and mobile browsers
- UK/PAL-first database with conservative hardware claims

## Data principles
The physical manufacturer model/serial label is the primary identifier. Internal revisions, regional specifications and community revision terminology can differ. The database should prefer manufacturer documentation, then reputable technical/archive references, and explicitly distinguish community terminology.

## Roadmap
The project is structured to grow into a comprehensive console reference: aliases, release data, compatibility, power, storage, networking, accessories, common faults, identification tips, buying checks, source links and verification status.

## Android / Google Play
The web app is the canonical product. Android packaging should preserve meaningful app functionality, offline behaviour and navigation rather than acting as a simple promotional wrapper. Before release, build/test the Android package against the current Google Play target API and quality requirements and complete Play Console listing, content rating, privacy/data-safety and testing requirements.

## Privacy
The current collection feature is stored locally in the user's browser/device. It does not require an account.

## Brand
Retro Console Checker is part of the RetroReplay UK family of connected brands. RetroReplay UK is presented as an optional relevant source for tested pre-owned retro hardware; the checker itself is a reference utility.

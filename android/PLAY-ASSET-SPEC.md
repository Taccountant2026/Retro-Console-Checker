# Retro Console Checker — Google Play visual assets

Production design direction: deep navy/black background, electric blue/cyan highlights, cream/white text, coral/red CHECKER accent, compact retro controller/console motif. Keep the app identity distinct from manufacturer trademarks and avoid implying endorsement by Sony, Nintendo, Sega, Microsoft or Atari.

## Required exports

- Play Store icon: 512 x 512 PNG, opaque, no external rounded-corner mask baked in.
- PWA icon: 192 x 192 PNG.
- PWA icon: 512 x 512 PNG.
- Maskable PWA icon: 512 x 512 PNG with important artwork inside the mask-safe area.
- Feature graphic: 1024 x 500 PNG/JPEG.
- Phone screenshots: capture the real production app after Android/TWA build; do not submit concept/mockup screens as if they are real app UI.

## Icon concept

RETRO / CONSOLE / CHECKER wordmark above a simple generic retro controller symbol. Electric-blue outer treatment, white/cream CONSOLE, coral/red CHECKER, dark navy background. Small details must remain legible at launcher size.

## Feature graphic copy

RETRO CONSOLE CHECKER
Identify • Check • Compare • Collect
UK/PAL-first retro console reference

## Screenshot story

1. Search by model code or console name.
2. Detailed model identification and used-hardware checks.
3. Compare up to three console models.
4. Save consoles to My Collection locally.
5. Surprise Me discovery.
6. Offline-ready installed app.

## Accuracy rule

Store screenshots must be generated from the actual release build. Marketing artwork may use illustrative console silhouettes, but must not fabricate app features, statistics, ratings, endorsements or compatibility claims.
